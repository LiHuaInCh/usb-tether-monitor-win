# USB 网络共享流量监控（Windows 桌面悬浮窗）

一个常驻桌面的小悬浮窗：实时显示 USB 网络共享（手机共享网络 / USB 绑网）的
**下载 / 上传速度**、**本次累计**和**监测时长**，并在底部展示**本次总量**
（自监控启动以来该网卡的累计收发，psutil 实时统计，准确无滞后）。

单文件、纯本地、无联网上报、不占用 Web 端口。

## 功能

- **自动识别网卡**：按网卡描述（RNDIS / USB Ethernet）找到 USB 网络共享接口，手机插拔后自动重新识别
- **实时速度**：下载 / 上传速度每秒刷新，数值过长时自动缩小字号防止两列重叠
- **本次总量**：底部一行展示「自监控启动以来」该网卡的累计收发总量（下载 + 上传合计）。
  数据来自 `psutil` 实时网卡计数器，准确且不滞后；与悬浮窗中间的「本次 ↓/↑」明细一致
- **预计 GB/H**：显示在「本次总量」右侧，按**最近 15 秒实测流量**外推的每小时用量（GB/小时）。
  取最近 15 秒滑动窗口内的实际收发求平均速率，比全程平均更贴近当前节奏、可减小瞬时误差；
  近 15 秒无流量时显示 0.00 GB/H
- **桌面悬浮窗**：
  - 半透明深色面板（80% 不透明度），可拖动到屏幕任意位置
  - 文字带柔和暗影，浅色壁纸下也清晰
  - 默认置顶显示
- **右键菜单**：「置顶 / 置底」切换、「重新监控」（清零本次累计收发与监测时长）、「退出」

## 运行环境

- Windows 10 / 11
- **系统 Python 3.9+**（需自带 tkinter；部分精简版 Python 不含 tkinter）
- 依赖：

  ```bash
  pip install psutil pywin32 Pillow
  ```

  - `psutil`：实时读取网卡流量（必需）
  - `pywin32`：网卡自动识别（WMI 查询 `Win32_NetworkAdapter`，可选；缺失时仍可手动用 `--iface` 指定网卡）
  - `Pillow`：悬浮窗离屏渲染（必需）
  - `tkinter`：分层窗口消息循环（系统 Python 一般自带）

## 使用

```bash
# 默认模式：桌面悬浮窗（自动识别 USB 共享网卡）
python usb_tether_monitor.py

# 指定网卡（默认自动识别）
python usb_tether_monitor.py --iface "以太网 2"
```

**拖动**：按住卡片任意位置即可拖动（整卡都可接收鼠标事件）。
**右键**：切换置顶 / 置底、退出。

> 快捷方式默认指向当前运行本脚本的 `pythonw`（无控制台窗口）。

## 实现要点

- **流量采样**：`psutil.net_io_counters(pernic=True)` 每秒读网卡字节数，差分得速率；
  「本次总量」为该网卡自监控启动以来的累计收发，按时间积分，准确反映真实用量
- **网卡识别**：`pywin32` + WMI 查询 `Win32_NetworkAdapter`（不依赖 powershell）
- **悬浮窗渲染**：Tk 只做消息循环，内容用 Pillow 离屏渲染（2x 超采样抗锯齿），
  通过 `UpdateLayeredWindow`（ULW_ALPHA）贴到分层窗口：
  - 整卡铺一层带 alpha 的底色（alpha>0 的像素才能被鼠标命中）
  - 相比 Tk 的 `-transparentcolor` 色键方案，不会出现「透明区域点击穿透到桌面」
  - 文字统一垫一层高斯模糊暗影，任何壁纸下都清晰
